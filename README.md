# solo-classicml

从零实现的经典机器学习库，仅用 Python 标准库、不联网。

- 入口：`python classicml.py <子命令>`
- 所有随机来源必须由显式随机种子决定；相同种子与输入必须产生逐字节相同的输出。
- 模型参数以 JSON 序列化，浮点数按固定小数位格式化。

## 测试

    python -m unittest discover

## 子命令

所有子命令从标准输入读取一个 UTF-8 JSON 对象，向标准输出写入紧凑 JSON（无空白、无尾换行）；输入非法时向标准错误写入 `ValueError: ...` 并以状态码 2 退出。

### train-linear

全批量梯度下降训练带可选 L2 惩罚的线性回归。输入对象的键依次为 `X, y, lr, l2, max_iter, tol`；`X` 为非空等宽二维数值数组，`y` 为等长数值数组，`lr`/`tol` 严格为正，`l2` 非负，`max_iter` 为正整数。输出对象的键依次为 `class, lr, l2, max_iter, tol, w, b`，权重与截距量化为 10 位小数。

输入：

    {"X":[[0.0],[1.0],[2.0]],"y":[0.0,1.0,2.0],"lr":0.1,"l2":0.0,"max_iter":100,"tol":0.000001}

输出：

    {"class":"LinearRegression","lr":0.1000000000,"l2":0.0000000000,"max_iter":100,"tol":0.0000010000,"w":[0.9989083937],"b":0.0015145228}

### train-logistic

全批量梯度下降训练二分类逻辑回归（标签为 `0`/`1` 且两类都必须出现）。输入/输出的键与数值规则与 `train-linear` 相同。

输入：

    {"X":[[0.0],[1.0],[2.0],[3.0]],"y":[0,0,1,1],"lr":0.5,"l2":0.0,"max_iter":200,"tol":0.000001}

输出：

    {"class":"LogisticRegression","lr":0.5000000000,"l2":0.0000000000,"max_iter":200,"tol":0.0000010000,"w":[3.3808677416],"b":-4.7688833061}

### predict-knn

用 k 近邻分类器对查询点投票预测。输入对象的键依次为 `X, y, n_neighbors, Q`；`X` 为训练样本矩阵，`y` 为等长整数标签，`n_neighbors` 为正整数且不超过训练样本数，`Q` 为与 `X` 等宽的查询矩阵。平票时取较小标签。输出对象的键依次为 `class, predictions`，每个查询点对应一个整数预测。

输入：

    {"X":[[0.0],[1.0],[2.0],[3.0]],"y":[0,0,1,1],"n_neighbors":1,"Q":[[0.5],[2.5]]}

输出：

    {"class":"KNeighborsClassifier","predictions":[0,1]}
